# 表格小帮手 1.0.0

单文件中文离线 Excel / CSV 整理工具。成品位于 `dist/表格小帮手.html`，双击用 Windows Chrome 或 Edge 打开，不用服务器，不用 Python，不用账号，不上传文件。

## 开发与复现

已实测工具链：Node.js 24.19.0、pnpm 11.19.0，Windows x64。所有直接依赖固定版本，间接依赖由 pnpm-lock.yaml 锁定，SheetJS 原始官方发行包保存在 vendor/。开发者安装依赖需要网络；顾客运行成品完全无需网络。

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm test:browser
pnpm package
```

构建无需启动开发服务器。esbuild 将 Excel、ZIP 引擎和 Web Worker 嵌入 HTML，界面只发送本机消息。CSP 阻止网络连接，图标为自有内联 SVG，字体使用系统中文字体，无外部字体包。重新构建的 HTML 应与相同工具链的交付文件 SHA-256 一致；ZIP 内时间戳固定以便核对。

浏览器测试需要已有 Chrome、Edge；通过 Playwright 官方 channel 启动。若缺少某浏览器，不要把 Chromium 测试冒充对应浏览器测试。`tests/browser.mjs` 使用 file://、离线浏览器上下文，验证下载内容、两个工作表选择、手机布局、错误和取消操作。核心测试会生成 `test-results/50000行.xlsx`，运行顺序应先 test，再 test:browser。浏览器不会读取真实用户文件。

`pnpm package` 先构建，再用现有测试 JSON 和截图生成中文报告、顾客包、开发者资料包与销售材料。运行测试后再打包，以便报告与代码保持一致。打包前先验证测试结果存在。输出保存在 `release/`，整个过程不公开发布。

## 结构

- `src/core.ts`：数据模型、限制、CSV 解析、安全 XLSX 读取、合并/去重/拆分/导出。
- `src/worker.ts`：后台状态与消息处理，结果保留在后台；导出不需要把全部记录传回界面。
- `src/app.ts`：中文工作流、加载/取消、规则失效处理、限量预览、安全 DOM 输出。
- `src/index.html` / `src/style.css`：离线界面。
- `scripts/build.mjs`：IIFE 与内嵌 Blob Worker 构建、许可收集。
- `tests/core.test.ts`：预先确定的期望内容与边界/性能测试。
- `tests/browser.mjs`：真实 Chrome/Edge 断网验收与截图。
- `scripts/package.mjs`：样例、说明、报告、销售页、ZIP、SHA-256 清单。
- `licenses/`：发行包原始许可和 NOTICE。未修改第三方源文件，只打包和压缩。

## 数据规则与范围

CSV 按文本读取；明确编码与分隔符选项，不自动猜测编码。首个非空 CSV 记录作为表头。UTF-8 / GB18030 解码使用浏览器原生 TextDecoder，错误字节拒绝，不用替换字符悄悄继续。CSV 引号、字段换行和分隔符经过往返测试，输出使用 UTF-8 BOM、逗号、双引号和 CRLF。

Excel 第一个已使用行作为表头，从 A 列开始；空列名/重复列名、合并单元格、宏、加密和特殊 ZIP 结构拒绝。普通数值保留数值，文本编号原样保留。纯零编号格式（如 000000）转显示文字；日期转日期时间文本。整数数值绝对值达到 10^15 时拒绝；工具无法恢复 Excel 之前丢失的精度，不能靠把错误数值改为文本恢复原编号。读取所有工作表后再由用户选择，所以未勾选工作表也计入读取上限。

公式只读取文件保存的缓存，不能重新计算。缺缓存变空值、错误值变可见错误文本，并计入异常单元格；没有缓存的全空行仍计入跳过行数。默认精确、区分类型；去空白只去首尾，不删中间空白。字符串“1”和数值 1 不相同。多字段键通过 JSON 数组编码避免碰撞，保留最后一条时仍按原行相对顺序输出。

XLSX 导出字符串是文本单元格，无 f 属性。CSV 对以 =、+、@、- 开始（包括前置空白）、前置制表/换行的可疑文本加英文单引号，普通合法负数与实际数值保留。安全前缀会改变 CSV 文本；保护数量可核对。CSV 不能控制 Excel 自动识别编号，优先 XLSX。输出不保留源样式、图片、筛选、批注、公式、宏、合并、超链接及其它工作簿结构，只交付数据表。

容量上限同时成立：10 文件；所有载入表合计 50,000 行、1,000,000 单元格（含表头）；200 列；10 MiB 单文件、25 MiB 合计；80 MiB XLSX 声明解压大小；30 工作表；100 拆分文件；32,767 字符单元格；120 秒超时。宽表会先达到单元格上限。XLSX 使用范围计数保守，过大的稀疏/残留格式范围可能被拒绝，请复制实际数据为新工作簿。生成的 XLSX 可能比 CSV 输入大；超过输入文件限制的输出需要拆小后才能再次载入。
